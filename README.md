# Personal portfolio

A responsive personal portfolio starter built with HTML, CSS, and JavaScript. No package installation or build step is required.

## Run locally

From the repository directory:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Open port 8000 in your local browser or your development environment’s supported port forwarding interface. Stop the server with Ctrl+C.

## Make it yours

- Edit `index.html` to replace Your Name, YN, the introduction, skills, project examples, page title, and description.
- Replace `you@example.com` in both the contact link and displayed text.
- Add real project links and images when available. The three current projects are sample placeholders.
- Change colors, spacing, and responsive styles in `styles.css`.
- Use `main.js` for page interactions; it currently updates the footer year.

## Publish

Deploy the repository root to any static website host. For GitHub Pages, choose the branch containing these files and the `/ (root)` folder in the repository’s Pages settings. No server-side services or secrets are required.

## Check changes

Run `node --check main.js`, start the local server, and check navigation, narrow-screen layout, and contact details before publishing. There is no automated test suite configured.
